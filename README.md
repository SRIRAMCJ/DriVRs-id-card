# Offline ID Card Generator

Open `index.html` directly in any modern browser.

Features:
- 100% client-side / offline
- No login
- No email
- No server
- No database
- No localStorage, cookies, or IndexedDB
- Drag-and-drop or file picker for photo
- Name, age, and license number
- Instant live ID card preview
- Reset
- Download ID card as PNG

The photo is kept only in browser memory as a temporary data URL. Refreshing or closing the page removes it.
